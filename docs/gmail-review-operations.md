# Gmail 审核修复与操作说明

2026年11月5日。此前 Google 回复由所有者发送；本次没有发送或改写邮件。修复只在任务分支准备，尚未发布到 AWS。

## 已完成的修复

Gmail 增量 history 使用 `labelId=INBOX`。对每个候选消息 ID，包括旧版本遗留队列，先用 `format=minimal&fields=id,labelIds` 读取标签；缺少 INBOX，或包含 SENT、DRAFT、SPAM、TRASH 时停止，不请求全文。只有符合条件才读取全文，并再次检查返回标签；不合适的响应不交给 AI 或保存提取记录。404 安全跳过；429/授权错误沿用原有重试/暂停行为，不能跳过标签检查。

标签检查与正文获取是两个独立请求，Gmail 不提供按标签原子读取正文的接口。期间被归档/移动的邮件可能短暂到达服务器，二次检查会将它排除。不能承诺任何并发变化下都绝不取回非收件箱正文。中英文隐私政策已同步说明这一数据边界，发布后需向审核方提供更新日期为 11 月 5 日的版本。初始近七天回填、分页游标、三封批次、用户确认和解绑语义保持不变。

生产环境新增限制：未验证 Gmail 默认禁止普通用户授权和后台同步，只对明确指定的 StudyBridge 测试账号 ID 开放。OAuth 开始、回调验证、连接建立、手动同步与后台工作器均检查；原有连接凭据/用户数据不会因此删除，解绑和清除提取记录始终可用。Google 基础登录及 Outlook 不受此限制。

## 部署配置

在服务器私有环境中设置（不把实际 ID、凭据或环境文件提交到仓库）：

```dotenv
GMAIL_SCOPE_VERIFIED=false
GMAIL_REVIEW_USER_IDS=STUDYBRIDGE_TEST_ACCOUNT_ID
```

多个测试 ID 以逗号分隔，精确匹配内部账号 ID；这不是邮箱地址。只有获得授权的审核账号才应加入。列表为空时全部生产 Gmail 授权和同步暂停。不要用所有者真实邮箱接收合成测试以外的数据来录屏。

仅在 Google 批准确切权限、完成所需独立安全评估并授权开放后，才将 `GMAIL_SCOPE_VERIFIED` 设置为精确字符串 `true`。任何其他值保持审核限制。配置验证脚本只在独立、无网络的子进程中允许虚构 configuration-check 账号，绝不把它加入服务器允许列表。

上线需按现有发布流程获得部署授权、检查私有备份并部署确切提交。保留既有 OAuth 客户端、加密密钥、连接、课程和日程；无需数据库迁移或重新申请权限。随后验证授权测试账号能连接/同步，普通账号不能开始授权或触发同步、已有非测试连接后台暂停，并验证各账号可解绑。对真实新账号执行一次 [审核材料中的操作路径](google-oauth-review-materials-2026-11-04.md)，仅使用合成邮箱。回退代码时注意旧版本不含审核隔离，必须在运营层继续限制测试范围。

## 测试证据

自动化使用模拟 Google/Microsoft 响应和合成数据，不访问真实邮箱或 OpenAI，不生成 CASA 证明。覆盖：每种排除标签及混合标签、标签缺失、最小字段预检、预检后归档/垃圾箱变化、两阶段 404、授权错误/限流、history 分页游标、旧队列到 AI 的隔离、生产账号精确匹配和默认关闭。既有 HTTP 流程验证注册、独立同意、授权状态/会话绑定、同步、显式确认、去重、解绑及保留已确认日程。

完整回归：532 项测试全部通过；源码、资源及版本检查通过 285 项。另有 21 项邮箱相关测试通过，包含模拟新账号全流程；这些数字不表示真实供应商验收。

## 运营方仍需完成

1. **真实授权和视频**：确认允许的独立测试账号，由账号所有者完成 Google 授权；录制基础登录权限、实际日历结果及解绑清除结果。展开 Gmail 权限和确认成功状态在旧视频中已有证据。新视频上传和更新申请前核对最终成片。
2. **OpenAI 数据设置**：在实际生产 API 所属组织/项目确认数据共享/训练 opt-in 关闭，记录无密钥截图和适用服务条款。`store:false` 不等于零留存。未核实前不能确认这一项通过；不擅自改变账号权限或法律协议。
3. **备份删除实践**：既有政策及 [删除 SOP 草案](google-oauth-review-materials-2026-11-04.md)已有流程；运营方必须确认真实备份位置、留存周期、必要留存依据和恢复后重新执行删除的机制，再用独立合成账号演练并记录。未经盘点不得自动清除真实备份，不能承诺未落实的完成天数。
4. **CASA**：由 Google 明确适用流程、评估方和提交要求。接受评估合同、付款、账号所有者声明以及提交最终证明需所有者操作或授权；代码测试不能代替认证。

上述事项需要账号所有权、实际运营信息或独立评估方参与，材料已准备但完成状态仍待实际证明。可先上线经验证的读取边界与审核限制，避免等待评估期间继续开放未批准范围。
